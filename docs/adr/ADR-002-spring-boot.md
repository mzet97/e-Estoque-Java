# ADR-002 — Spring Boot 4.1.1 (GA)

**Status:** Aceito · **Data:** 2026-09-04

**Contexto:** Última GA estável em 2026-09-04 é 4.1.1 (2026-08-21); 4.2 existe só como milestone. Baseline verificada em spring.io.
**Decisão:** Spring Boot 4.1.1 + Spring Framework 7 (BOM gerencia versões); Spring MVC (não WebFlux) pela stack JPA bloqueante; springdoc-openapi 3.1.0 (linha Boot 4).
**Consequências:** Nenhuma milestone/RC/SNAPSHOT; starters gerenciados; upgrades seguem apenas GAs.
